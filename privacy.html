Zur Verwaltung und Automatisierung unseres Pinterest-Kanals nutzen wir die offizielle Pinterest REST API (API v5). Unsere entwickelte Anwendung trägt den Namen Innosafer Publisher.

Zweck & Datenumfang der Pinterest Anwendung / API Data Declaration:

  • Application Purpose: Innosafer Publisher is used exclusively to automate the creation, scheduling, and publishing of curated home and kitchen product pins directly to our own official Pinterest business account.
  • No 3rd-Party User Data Collection: The application operates solely on our authenticated brand account via OAuth 2.0. It does not access, read, collect, or process data from any third-party Pinterest users.
  • API Scopes Requested: `boards:read`, `boards:write`, `pins:read`, `pins:write`. Access tokens are stored securely and used strictly for automated publishing.
